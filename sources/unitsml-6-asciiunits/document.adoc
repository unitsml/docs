== Foreword

The unit expression is the connective tissue of the series: it is the content of `unitsml(...)` in legacy dialects, of the `unit(...)` constructor in pma, and the payload of every dimension decomposition. This part specifies that language as a grammar-only artifact: a PARG grammar compiled to a checksummed artifact, terminals generated from the register, and a corpus frozen as the conformance reference. No runtime code lives beside the grammar; runtimes are separate implementations (Ruby, TypeScript) of the same artifact.

== Scope

This document specifies the expression surface; the terminal-generation rule from the register (UnitsML 3); the registration of multi-term and prefixed symbols; extender rules; and the artifact contract. It does not define the embedding syntax of host languages (their parts do that) nor any semantics beyond parsing to a formula tree.

== Normative references

* UnitsML 1, UnitsML 3

== Expression grammar

The artifact (`artifacts/unitsml.json`, checksummed) is normative; this clause orients. The surface:

- **products**: juxtaposition with a single separating space (`kg m`);
- **quotients**: `/` and `//`, the latter inverting the exponent of the following factor (`m/s^2`, `J//kg` forms);
- **powers**: `^` with integer and specified-fraction numerators; **roots**: `sqrt(...)`;
- **grouping**: parentheses;
- **extenders**: continuation marks for interrupted series, legal only inside an expression — a trailing extender is rejected (grammar v2);
- **dimension symbols**: `dim_L`, `dim_M`, `dim_I`, `dim_Θ`, `dim_N`, `dim_J`, `dim_Φ` for dimension-only expressions;
- **the number `1`**: the identity expression.

== Terminal generation from the register

Every unit symbol, prefix symbol and registered multi-term symbol is generated from the UnitsDB 3 release. The grammar never hardcodes vocabulary: a register edit regenerates the terminals. Registered prefixed symbols (dB, mbar, kgf, cSt, …) are single terminals, resolved deterministically against prefix+unit decompositions; registration order and precedence are part of the generated tables.

== Whitespace and lexical discipline

A single space separates juxtaposed factors; no space occurs inside a terminal; multi-term registered symbols match as whole tokens before sub-term decomposition. The lexer is owned by the grammar — no consumer-side re-lexing.

== The artifact contract

- The artifact carries a checksum set; every consuming runtime MUST verify checksums before load.
- The artifact records its grammar edition; edition 2 carries grammar v2 (registered prefixed symbols, trailing-extender rejection).
- Grammar edits regenerate the artifact AND the corpus in the same change; consuming-runtimes CI (dependent-gems against unitsml-ruby) gates the regeneration.
- The corpus: 143 cases covering every terminal class and every production of Clause 5, frozen byte-for-byte.

== Conformance

The 143-case corpus replayed by unitsml-ruby, unitsml-ts and asciiunits-ts; the embedding vectors of UnitsML 8 Annex B for host-language integration.
