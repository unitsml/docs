== Status of this draft

The grammar and artifact are implemented and shipped (asciiunits 0.1.x grammar v2; PARG artifact; 143-case corpus). This part formalizes the implemented contract.

== Abstract

The grammar-only content language embedded by `unitsml(...)` (dialect L) and `unit(...)` (dialect P): expression surface — products, quotients with exponent inversion, integer and specified-fraction powers, `sqrt(...)`, parentheses, extenders with trailing-extender rejection, the dimension symbols `dim_L…dim_Φ`, and the number `1`. Terminals are generated from the UnitsDB 3 register (unit symbols, prefix symbols, registered multi-term and prefixed symbols such as dB, mbar, kgf, cSt) so register and grammar cannot drift. The artifact contract: `artifacts/unitsml.json` with checksums, an edition field, regeneration in the same change as any grammar edit, and the 143-case corpus as the normative conformance reference for every consuming runtime.
