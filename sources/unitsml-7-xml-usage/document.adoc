== Status of this draft

Base document landed: "UnitsML XML Schema specification" (unitsml/docs PR #9) — the lutaml_xsd-generated specification of unitsml-v1.0.xsd covering all 96 schema components, enumerations and examples. That document specifies SYNTAX; this part specifies USAGE semantics. Drafting order position: after Parts 4, 5 and the Plurimath 2 model.

== Abstract

How conforming producers emit and consumers interpret UnitsML 1.0 documents: the emitted element set (`Unit`, `Prefix`, `Quantity`, `Dimension`, `QuantityReference`, `Conversions`) with `xml:id` allocation; `QuantityReference` selection per the UnitsML 3 primary-reference rule (never positional `.first`); `Conversions` emission with the full affine attribute set of UnitsML 5 (never synthetic `SpecialConversionFrom`/`WSDLConversionFrom`); `xref` linking from MathML into the document (consumed by the Plurimath embedding clauses); schema-version declaration; deterministic reading of foreign payloads (the openCDD corpus's duplicate lowercase attributes are tolerated on read, never reproduced on write); and the recorded gap — UnitsML 1.0 has no first-class uncertainty element — with Annex B (informative) proposing a `MeasurementResult` sibling of `QuantityReference` (category, exact decimal text, k, p, interval kind/endpoints, JCGM 101 distribution parameters) as a WG-path proposal.
