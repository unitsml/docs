= UnitsML 1.0 schema source provenance

The schema in `unitsml-v1.0.xsd` is generated from the UnitsML schema project
inputs used for the published final 1.0 reference. The optional `schemaLocation`
was omitted from the XML namespace import so schema documentation builds do not
need network access; the import namespace and schema declarations are unchanged.
The schema template and generator are from `unitsml/schemas` commit
`de016581e4ab886550608ae26fd457f669b0938f`. The `unitsdb/units.yaml` and
`unitsdb/prefixes.yaml` inputs are from commit
`651384b0300b79489274c117a3ea4a860a806e84`, the UnitsDB main revision before
the published reference was deployed.

The original generator expands both YAML files into `items` XML, then runs
`templates/xsdprocess.xsl` over `templates/unitsml-v1.0.template`. The resulting
schema has namespace `https://schema.unitsml.org/unitsml/1.0`. Its 298
enumeration values exactly match the values rendered in the published schema
reference, and its non-annotation, non-enumeration structure matches the
maintained final 1.0 XSD.

* `prefixes.yaml`: `25c804e6e7951eb0605608002e23f3439e58ce83e3ba410cae91370fff420625`
