== Abstract

The conformance contract for all implementations: the corpora layout (`corpora/renders`, `corpora/uncertainty`, `corpora/conversion`, `corpora/conformance`) with a versioned index; the vector file format — inputs, expected results as exact decimal strings (UnitsML 2), per-vector metadata (source clause, engine/grammar/vector-set versions, declared tolerance `|computed − expected| ≤ 10^−d·|expected|` where non-exact); replay-harness requirements per language (Ruby, TypeScript, Rust lanes; byte-identical output; releases blocked on drift); the runtime conformance classes (parse/render; quantity and conversion; evaluation; full-series) and the claims each licenses; and the Monte Carlo reproducibility classes (byte-exact under pinned Wichmann–Hill vs distributional with stated tests; MCMC-draw examples excluded from byte vectors).
