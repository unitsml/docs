== Annex (informative): additional test-suite examples

[example]
*Exact flag discipline.* `exact="false"` percent-per-degree (`0.5729577951308232087679815481`): the result carries the declared digits, the vector declares `tolerance_d`, and the output MUST NOT contain an `exact` marker.

[example]
*No float leakage.* Grep gate: no serialized corpus artifact contains a decimal exponent form (`e-17`) originating from a binary double; guard-digit strings only.

[example]
*Stamp integrity.* Two vectors with differing `numeric_algorithm` stamps MUST NOT be byte-compared against each other; the harness rejects the cross-stamp comparison.
