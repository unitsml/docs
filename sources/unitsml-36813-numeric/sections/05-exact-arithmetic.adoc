== Exact rational arithmetic

Conversions declared `exact="true"` (CalConnect 36816, scale and difference arithmetic (CalConnect 36815, Type A statistics, and all rational operations of propagation are computed in exact rational arithmetic; an implementation never rounds an intermediate exact value.

Irrational results — square roots of non-square rationals, Student-t quantiles — are computed by the declared algorithm of Clause 7 or refused — never through a floating-point shortcut.

[example]
*Expected outcome.* Converting 32 °F to kelvin: the factor 5/9 and the offset arithmetic run in rationals; the serialized result is exactly `"273.15"`. A float path would emit platform-dependent digits at the tail.

[example]
*Refusal expected.* `sqrt` over a non-square rational factor in a canonical decomposition has no exact rational result; the conversion of such a synthetic unit is refused with a typed error, not approximated.
