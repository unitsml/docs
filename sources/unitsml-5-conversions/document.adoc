== Abstract

The UnitsML conversion law `y = d + (b/c)(x + a)` and its inverse `x = (c/b)(y − d) − a`: attribute semantics (`initialUnit`, `initialAddend` a, `multiplicand` b, `divisor` c, `finalAddend` d, `exact`, digit metadata); exactness discipline (rationals for `exact="true"`, lexical decimal preservation, no float drift, no silent precision loss for `exact="false"`); the difference application law (offsets cancel on differences — factor-only; affine legal only at power 1 and only for absolute values); application precedence (caller-supplied definition → document `<Conversions>` → register canonical path, with the agreement diagnostic and no double application); `initialUnit` resolution (document fragment, SI Digital Framework URI, IEC IRDI; unresolvable is a typed error); refusal semantics for `SpecialConversionFrom`/`WSDLConversionFrom`.
